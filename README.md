# Recruitment_data_analysis
## Overview

A data analysis project built entirely in Excel to evaluate recruitment pipeline performance across a 2,400-candidate HR dataset. The goal was to clean messy raw data, compute key hiring metrics, and surface insights through a structured dashboard.

## Metrics calculated

1. App to Interview (Days)Interview Date
 
2. Time to Hire (Days)Job Offer Date
   
3. Time to Publish Advert (Days)Advert Open Date
   
4. Open Days
   
5. End of Probation Date
   
6. Onboarding to File Opening (Days)
   
7. Interview to Reporting (Days)
   
8. Time to Approve Requisition (Days)Approval Date
   
9. Time to Close Employee File (Days)File Closure Date
    
10. Inclusion to Benefits (Days)

## Key Numbers (from the dataset)

* 2,400 total candidate records
* 397 hired (~16.5% acceptance rate)
* 10 departments represented
* 3 candidate sources: Job Board, LinkedIn, Referral

## Notes

The End of Probation Date column uses a 30-day-per-month approximation based on the probation period in months
